# Data Directory

This directory contains the synthetic banking datasets used in the Banking Analytics Lakehouse POC.

## Directory Structure

```
data/
└── sample/
    ├── customers.csv       # 20 customer records
    ├── accounts.csv        # 20 account records
    └── transactions.csv    # 100 transaction records
```

---

## Dataset Descriptions

### `customers.csv`

Synthetic customer master data.

| Column | Type | Description |
|---|---|---|
| `customer_id` | String | Unique customer identifier (`CUST_001`…`CUST_020`) |
| `name` | String | Synthetic name (`User_1`…`User_20`) |
| `country` | String | Randomly selected from: `USA`, `UK`, `India`, `Germany` |

- **Rows:** 20
- **Nulls:** 0
- **Duplicates:** 0

> **Dataset Note:** The capstone specification defines optional/additional `email` field. The supplied synthetic dataset generated for this implementation does not include this column. `email` is documented as a future/optional enhancement.

---

### `accounts.csv`

Synthetic bank account data linked to customers.

| Column | Type | Description |
|---|---|---|
| `account_id` | String | Unique account identifier (`ACC_001`…`ACC_020`) |
| `customer_id` | String | Foreign key → `customers.customer_id` |
| `account_type` | String | Randomly selected: `Savings` or `Current` |

- **Rows:** 20
- **Nulls:** 0
- **Duplicates:** 0
- **Relationship:** Each account maps 1:1 to a customer in this dataset.

> **Dataset Note:** The capstone specification defines optional/additional `balance` field. The supplied synthetic dataset does not include this column. `balance` is documented as a future/optional enhancement.

---

### `transactions.csv`

Synthetic banking transaction data.

| Column | Type | Description |
|---|---|---|
| `tx_id` | String | Transaction ID (`TX_NNNNN`, random 5-digit suffix) |
| `account_id` | String | Foreign key → `accounts.account_id` |
| `amount` | Float | Transaction amount: `10.00`–`5000.00` |
| `tx_type` | String | `Credit` or `Debit` |
| `timestamp` | String | ISO datetime; within previous 30 days of generation |

- **Rows:** 100
- **Nulls:** 0
- **Duplicates:** 0
- **Amount range:** 10.00–5000.00
- **Relationship:** All `account_id` values reference valid accounts.

---

## Generation Method

Datasets are generated by [`src/data_generation/generate_banking_data.py`](../src/data_generation/generate_banking_data.py).

```bash
python src/data_generation/generate_banking_data.py
```

The script uses `pandas`, `random`, and `datetime` to produce deterministic-looking synthetic data. No real customer or financial data is used.

---

## Relationships

```
customers.customer_id  (PK)
        └──→  accounts.customer_id  (FK)
                        └──→  transactions.account_id  (FK → accounts.account_id)
```

---

## Upload to S3 (AWS)

After generation, upload to your raw S3 bucket:

```bash
aws s3 cp data/sample/customers.csv    s3://<your-raw-bucket>/customers/
aws s3 cp data/sample/accounts.csv     s3://<your-raw-bucket>/accounts/
aws s3 cp data/sample/transactions.csv s3://<your-raw-bucket>/transactions/
```
